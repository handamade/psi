## Choices the spec leaves open

- **Opening shows the whole list; typing filters.** Arrow keys and the chevron
  open the list unfiltered, even when a single-select's input holds the picked
  label; the filter applies from the first keystroke. Otherwise reopening a
  picked single-select would show one option.
- **The highlight's "nothing" and "first" are different states.** Typing sets
  it to follow the first match (so an async read that lands later still
  highlights its first option). Alt + Down opens with nothing highlighted, as
  the key table says. An explicit highlight is kept by value; when its option
  goes, the highlight moves to the first, or clears on an empty list.
- **Enter with the list open never submits,** even with nothing highlighted:
  the key belongs to the list while it's open.
- **Esc that clears the text also stops propagation,** so a Dialog doesn't
  close on the same key. With no text and the list closed, Esc passes through.
- **A click on the input doesn't open the list** (React Aria's default
  `menuTrigger="input"`): typing, the arrow keys and the chevron do.
- **Blur closes the list.** A pointerdown in the popup or on the control's
  buttons calls `preventDefault()` on `pointerdown` and `mousedown`, so it
  never blurs.
- **`required`** sets `aria-required` and a custom validity, not the native
  attribute: native `required` reads the text, which is empty in a
  multi-select that has values. The message is the browser's own, read from a
  detached `<input required>`, so it is localised with no new prop.
- **The Tag remove buttons get `tabindex="-1"`** from an effect on the
  control, since Tag has no prop for its button and the spec adds only
  `dismissLabel`.
- **One live region speaks the count, the loading line and "No matches";**
  the visible status lines are not live, so nothing is said twice.
- **A label cache** keeps a picked value's label when a caller-owned list
  (`filter={false}`) no longer contains it.
- **Open stories open only under `vr`,** like Tooltip's, so the docs page and
  the Storybook canvas start closed.
