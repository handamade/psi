# Application Shell (D88) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Tasks 1–3 run **sequentially**: they share registration files. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A desktop application frame: a skip link, a full-width header that labels its links, a collapsible dark sidebar holding a grouped navigation tree that marks the current page, and a `main` that scrolls on its own so nothing hides under the header.

**Architecture:** `NavBar` gains three props and stops rendering an empty `<nav>`. Five new components: `SkipLink` (a styled anchor), `NavTree`/`NavGroup`/`NavItem` (native list, buttons and links), `AppShell` (a grid filling the viewport). Two token files (`skip-link`, `nav-tree`) plus `app-shell`'s width; no new contrast pairs. One pattern.

**Tech Stack:** React 19, CSS Modules, Vitest + Testing Library, axe, Playwright over built Storybook.

Spec: `docs/superpowers/specs/2026-10-01-app-shell-design.md`.

## Global Constraints (every task)

- Node 24 (`node -v`). Zero runtime dependencies. No `style` prop in components, no `url()` in CSS, no HTML sink (strict CSP, consumer rule 3).
- Every new prop defaults to today's behaviour. No existing test edited, except a count.
- Colours only through `var(--psi-*)`; focus rules bind `--psi-focus-ring-width` / `--psi-focus-ring-offset(-inset)` (stylelint `psi/focus-ring`); `--psi-space-*` binds gap/padding/margin only, never `height`.
- Every focusable element in a story draws the shared ring — the D82 sweep (`apps/storybook/vr/focus-ring.interaction.spec.ts`) fails CI otherwise.
- Never `pnpm test:e2e --grep <story word>` (matches the screenshot spec and writes `-darwin` junk). Run the full `pnpm test:e2e`, or grep an interaction title.
- No `git commit --amend`, no force push. No VR baselines.
- Report back: red count before, green count after, lint result, and every deviation from this plan with its reason.
