# A homepage that leads into the system (D133) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the seven-section homepage with a short front door (hero and theme console, a surfaces map and trace, the Canopy demo, the four rules), move releases to `/docs/changelog/`, and give the whole site a shared header, a phone bottom bar and Rubik type.

**Architecture:** `index.astro` composes static Astro sections. Four React islands carry the interaction: site chrome, theme console, trace, Canopy. Every excerpt, count and date is computed at build from the packages' own artifacts. Islands share nothing but `<html>` attributes and custom properties.

**Tech Stack:** Astro 7, React 19, `@handamade/psi-react` (workspace), `@handamade/psi-docs` (workspace, private), `@handamade/psi-mcp` (workspace), Fontsource, Vitest (jsdom), Playwright (`test:site`).

**Spec:** `docs/superpowers/specs/2026-11-17-homepage-design.md`. Read it before Task 1.

## Global Constraints

- Node 24: run `nvm use` in the repo root before the first `pnpm` command. pnpm dies on Node 20.
- The gates, all five, in this order: `pnpm build && node tools/check-docs-drift.mjs && pnpm test && pnpm lint && pnpm --dir apps/site build && pnpm test:site`. `test:site` runs from the repo root, after a full build.
- Never hardcode a colour in CSS: bind `var(--psi-*)`. The stylelint plugin enforces it in packages; keep to it in `apps/site` too.
- Sizes are px numbers (`24 | 32 | 40 | 48`), never S/M/L. Variants are flat (`accent`, `neutral-subtle`, …). One accent per visual group.
- Breakpoints: `breakpoints.md` = 960px for the page's own layout, `breakpoints.sm` = 560px for Canopy's own width (D31). No others.
- No numbered eyebrows, no stat chips, no grid of equal cards. Each section: heading, one lede sentence, content, a docs link.
- Values written `<like this>` in the spec are generated at build, never typed.
- Nothing in this repo names a consumer project or the private request register.
- No changeset: `apps/site` and `packages/docs` are private (D121 precedent).
- `vr` is untouched: the homepage is not in Storybook.
- Branch: `d133-homepage`. Commit after each task. Re-check D133 is still free before opening the PR.

## Two deviations from the spec, decided while planning

1. **The MCP `check` excerpt is computed in `apps/site`, not in `packages/docs`.** `@handamade/psi-mcp` depends on `@handamade/psi-docs`, so `traceFor` in `packages/docs` cannot import `checkMarkdown` without a cycle. `traceFor` returns every surface except `mcp`; `apps/site/src/lib/trace-data.ts` adds it. `apps/site` gains a workspace dependency on `@handamade/psi-mcp`.
2. **The map's SVG is rendered by the trace island, not by a separate Astro component.** The island is server-rendered, so the map is still HTML with no JavaScript. One component owning both the map and its highlight avoids reaching across island boundaries with DOM queries.

Task 13 records both in the spec.

```ts
export type ModePref = Mode | "system";

/**
 * The visitor's preference, with "system" as a real choice (D133): picking it
 * removes the stored mode, so the OS-follow listener in this hook takes over
 * again. `mode` is what is painted. setModeEphemeral is useMode's, for a
 * derived brand's own mode (never persisted).
 */
export function useModePref(): [ModePref, Mode, (p: ModePref) => void, (m: Mode) => void] {
  const [pref, setPrefState] = useState<ModePref>("system");
  const [mode, setModeState] = useState<Mode>("light");
  useLayoutEffect(() => {
    const stored = readStoredMode();
    setPrefState(stored ?? "system");
    setModeState(stored ?? systemMode());
  }, []);

  const setPref = useCallback((p: ModePref) => {
    setPrefState(p);
    const next = p === "system" ? systemMode() : p;
    setModeState(next);
    applyMode(next);
    try {
      if (p === "system") localStorage.removeItem(MODE_KEY);
      else localStorage.setItem(MODE_KEY, p);
    } catch {
      /* storage unavailable */
    }
  }, []);

  const setModeEphemeral = useCallback((m: Mode) => {
    setModeState(m);
    applyMode(m);
  }, []);

  useEffect(() => {
    const mq = matchMedia("(prefers-color-scheme: dark)");
    const onChange = () => {
      if (readStoredMode() !== null) return;
      const next: Mode = mq.matches ? "dark" : "light";
      setModeState(next);
      applyMode(next);
    };
    mq.addEventListener("change", onChange);
    return () => mq.removeEventListener("change", onChange);
  }, []);

  return [pref, mode, setPref, setModeEphemeral];
}
```

```ts
import { useLayoutEffect, useState } from "react";

/** `breakpoints.md` (D31). docs.css and chrome.css bake the same 960px. */
export const WIDE = "(min-width: 960px)";

/** A media query's state. The server and the first client render use
 * `serverDefault`, so hydration never mismatches; the real value lands
 * before paint. */
export function useMatchMedia(query: string, serverDefault: boolean): boolean {
  const [matches, setMatches] = useState(serverDefault);
  useLayoutEffect(() => {
    const mq = window.matchMedia(query);
    const sync = () => setMatches(mq.matches);
    sync();
    mq.addEventListener("change", sync);
    return () => mq.removeEventListener("change", sync);
  }, [query]);
  return matches;
}
```

export function SiteChrome({ sidebar }: { sidebar?: { open: boolean; onToggle: () => void; id: string } } = {}) {
  const [pref, , setPref] = useModePref();
  const [menuOpen, setMenuOpen] = useState(false);
  const [searchOpen, setSearchOpen] = useState(false);
  const menuButton = useRef<HTMLButtonElement>(null);

  // Ctrl+K is kill-line in a macOS text field, so Apple platforms get Meta+K
  // only (moved here from DocsShell unchanged).
  const [apple, setApple] = useState(false);
  useLayoutEffect(() => {
    const nav = navigator as Navigator & { userAgentData?: { platform?: string } };
    setApple(/Mac|iPhone|iPad|iPod/i.test(nav.userAgentData?.platform || nav.userAgent));
  }, []);
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if ((apple ? e.metaKey : e.ctrlKey) && e.key.toLowerCase() === "k") {
        e.preventDefault();
        setSearchOpen(true);
      }
    };
    window.addEventListener("keydown", onKey);
    return () => window.removeEventListener("keydown", onKey);
  }, [apple]);

  const closeMenu = () => {
    setMenuOpen(false);
    menuButton.current?.focus();
  };

  return (
    <>
      <SearchDialog open={searchOpen} onClose={() => setSearchOpen(false)} />
      <header className="site-header">
        <a className="wordmark" href="/" aria-label="Psi, home">
          <PsiMark size={24} />
          <span aria-hidden="true">psi</span>
        </a>
        <nav className="site-nav" aria-label="Site">
          {PAGES.map(([label, href]) => (
            <a key={href} href={href}>{label}</a>
          ))}
        </nav>
        <span className="site-header-space" />
        <Button size={24} variant="neutral-subtle" onClick={() => setSearchOpen(true)} aria-keyshortcuts={apple ? "Meta+K" : "Control+K"}>
          Search
        </Button>
        <span className="site-header-mode">
          <ModeControl pref={pref} onPref={setPref} />
        </span>
      </header>

      <nav className="site-bottom-bar" aria-label="Site, bottom">
        {PAGES.map(([label, href]) => (
          <a key={href} href={href}>{label}</a>
        ))}
        <button ref={menuButton} type="button" aria-expanded={menuOpen} aria-controls="site-menu" onClick={() => setMenuOpen(true)}>
          <IconMenu size={16} aria-hidden="true" />
          Menu
        </button>
      </nav>

      <Dialog id="site-menu" open={menuOpen} onClose={closeMenu} placement="inline-end" width={400} title="Menu">

          <Button variant="neutral" size={40} aria-controls={sidebar.id} aria-expanded={sidebar.open}

import type { UpdateEntry } from "../content/updates";

const SITE = "https://psi.kurkin.de";

export function changelogMd(entries: UpdateEntry[]): string {
  const parts = ["# Changelog", "", "Every Psi release, newest first."];
  for (const e of entries) {
    parts.push("", `## ${e.title}`, "", `${e.date} · ${e.tag}`, "", e.body);
    if (e.link) {
      const href = e.link.href.startsWith("/") ? `${SITE}${e.link.href}` : e.link.href;
      parts.push("", `[${e.link.label}](${href})`);
    }
  }
  return parts.join("\n") + "\n";
}

import { existsSync, readdirSync, readFileSync } from "node:fs";
import { join } from "node:path";

import { docSection, kebab } from "./data.js";
import { componentPages } from "./pages.js";
import { EXAMPLES_DIR, getExport, readGeneratedDoc, reactRoot, resolved, tokensRoot } from "./node.js";

export type Surface = "code" | "docs" | "storybook" | "figma" | "llms" | "md" | "mcp";
export type TraceTarget = "Button" | "Field" | "Table" | "--psi-fg-accent";
export interface Excerpt { kind: "text" | "rows"; text?: string; rows?: string[][]; from: string; href?: string; hrefLabel?: string }
export class TraceError extends Error {}

/** Psi Token Sync groups colour variables by their first word: fillAccent → fill/accent. */
const figmaName = (cssVar: string) => cssVar.replace(/^--psi-/, "").replace("-", "/");

function slugOf(name: string): string {
  const page = componentPages.find((p) => p.members.includes(name));
  if (!page) throw new TraceError(`trace: no docs page for "${name}"`);
  return page.slug;
}

function stories(name: string): { title: string; names: string[]; path: string } {
  const dir = join(reactRoot, "src", name);
  const file = existsSync(dir) ? readdirSync(dir).find((f) => f.endsWith(".stories.tsx")) : undefined;
  if (!file) throw new TraceError(`trace: ${name} has no story file in packages/react/src/${name}/`);
  const src = readFileSync(join(dir, file), "utf8");
  const title = src.match(/title:\s*["'`]([^"'`]+)["'`]/)?.[1];
  const names = [...src.matchAll(/^export const (\w+)\s*:/gm)].map((m) => m[1]);
  if (!title || names.length === 0) throw new TraceError(`trace: ${file} has no title or no stories`);
  return { title, names, path: `packages/react/src/${name}/${file}` };
}

function componentTokens(name: string): string[] {
  const css = readFileSync(join(tokensRoot, "dist", "components.css"), "utf8");
  const prefix = `--psi-${kebab(name)}-`;
  return [...css.matchAll(/(--psi-[a-z0-9-]+):\s*var\((--psi-[a-z0-9-]+)\)/g)]
    .filter((m) => m[1].startsWith(prefix) && !m[2].startsWith(prefix))
    .map((m) => `${m[1]}  →  ${figmaName(m[2])}`);
}

function llmsLines(name: string): string {
  const lines = readFileSync(join(reactRoot, "llms.txt"), "utf8").split("\n");
  const own = lines.filter((l) => l.includes(name));
  const rules = docSection(lines.join("\n"), "Rules for generated code")?.split("\n").filter((l) => l.startsWith("- ")) ?? [];
  return [...new Set([...own, ...rules])].slice(0, 8).join("\n");
}

function componentTrace(name: string): Record<Exclude<Surface, "mcp">, Excerpt> {
  const slug = slugOf(name);
  const exampleDir = join(EXAMPLES_DIR, slug);
  const example = readdirSync(exampleDir).filter((f) => f.endsWith(".tsx")).sort()[0];
  if (!example) throw new TraceError(`trace: no example in packages/docs/examples/${slug}/`);
  const info = getExport(name);
  const s = stories(name);
  const md = readGeneratedDoc(name);
  return {
    code: { kind: "text", text: readFileSync(join(exampleDir, example), "utf8").trim(), from: `packages/docs/examples/${slug}/${example}` },
    docs: {
      kind: "rows",
      rows: info.props.filter((p) => p.name !== "ref" && p.name !== "className").map((p) => [p.name, p.type, p.default == null ? "—" : String(p.default)]),
      from: "manifest.json",
      href: `/docs/components/${slug}/`,
      hrefLabel: "Open the docs page",
    },
    storybook: { kind: "text", text: [s.title, ...s.names.map((n) => `  ${n}`)].join("\n"), from: s.path, hrefLabel: "Open in Storybook" },
    figma: { kind: "text", text: componentTokens(name).join("\n") || "(no component tokens)", from: "Psi Token Sync, generated from components.css", hrefLabel: "Open in Figma" },
    llms: { kind: "text", text: llmsLines(name), from: "packages/react/llms.txt", href: "/llms.txt", hrefLabel: "/llms.txt" },
    md: { kind: "text", text: md.split("\n").slice(0, 14).join("\n"), from: `packages/react/docs/${name}.md`, href: `/docs/components/${slug}.md`, hrefLabel: `/docs/components/${slug}.md` },
  };
}

function tokenTrace(cssVar: string): Record<Exclude<Surface, "mcp">, Excerpt> {
  const name = Object.keys(resolved("light").tokens).find((k) => `--psi-${kebab(k)}` === cssVar);
  if (!name) throw new TraceError(`trace: no semantic token ${cssVar}`);
  const t = resolved("light").tokens[name];
  return {
    code: { kind: "text", text: `color: var(${cssVar});\n\n/* ${t.formula} */`, from: "packages/tokens/src" },
    docs: { kind: "rows", rows: (["light", "dark", "acme", "ember"] as const).map((th) => [th, resolved(th).tokens[name].hex]), from: "resolved/<theme>.json", href: "/docs/tokens/color/", hrefLabel: "Open the colour tokens" },
    storybook: { kind: "text", text: "Tokens and Assets/Color Tokens", from: "apps/storybook", hrefLabel: "Open in Storybook" },
    figma: { kind: "text", text: `${figmaName(cssVar)}\n  Light · Dark · Acme · Ember`, from: "Psi Token Sync", hrefLabel: "Open in Figma" },
    llms: { kind: "text", text: readFileSync(join(tokensRoot, "llms.txt"), "utf8").split("\n").filter((l) => l.includes("fg-") || l.includes("formula")).slice(0, 6).join("\n"), from: "packages/tokens/llms.txt", href: "/llms.txt", hrefLabel: "/llms.txt" },
    md: { kind: "text", text: "# Color tokens", from: "docs/tokens/color.md", href: "/docs/tokens/color.md", hrefLabel: "/docs/tokens/color.md" },
  };
}

export function traceFor(target: TraceTarget): Record<Exclude<Surface, "mcp">, Excerpt> {
  return target.startsWith("--psi-") ? tokenTrace(target) : componentTrace(target);
}

import { checkMarkdown, loadIndex } from "@handamade/psi-mcp";
import { traceFor, type Excerpt, type Surface, type TraceTarget } from "@handamade/psi-docs/trace";

export const TARGETS: TraceTarget[] = ["Button", "Field", "Table", "--psi-fg-accent"];

/** What a wrong call looks like for each target: the MCP tab shows `check`,
 * not `get`, because `get` returns exactly the Markdown tab's text (D129). */
const WRONG: Record<TraceTarget, string> = {
  Button: '<Button variant="primary" size="md">Save</Button>',
  Field: '<Field label="Email"><Input size="lg" /></Field>',
  Table: "<Table><TableRow><TableCell>1</TableCell></TableRow></Table>",
  "--psi-fg-accent": '<Button variant="secondary">Save</Button>',
};

export async function buildTraceData(): Promise<Record<TraceTarget, Record<Surface, Excerpt>>> {
  const index = await loadIndex();
  const out = {} as Record<TraceTarget, Record<Surface, Excerpt>>;
  for (const t of TARGETS) {
    const call = WRONG[t];
    out[t] = {
      ...traceFor(t),

    };
  }
  return out;
}

```tsx
import { useState } from "react";
import { SegmentedControl, Segment, Tab, TabList, TabPanel, Tabs, Link } from "@handamade/psi-react";
import type { Excerpt, Surface, TraceTarget } from "@handamade/psi-docs/trace";

import { useMatchMedia, WIDE } from "../chrome/useWide";
import { SurfaceMap } from "./SurfaceMap";

const SURFACES: [Surface, string][] = [["code", "Code"], ["docs", "Docs"], ["storybook", "Storybook"], ["figma", "Figma"], ["mcp", "MCP"], ["llms", "llms.txt"], ["md", "Markdown"]];
const TARGET_LABEL: Record<TraceTarget, string> = { Button: "Button", Field: "Field", Table: "Table", "--psi-fg-accent": "Token" };

function ExcerptView({ e, href }: { e: Excerpt; href?: string }) {
  return (
    <div className="trace-excerpt">
      {e.kind === "rows" ? (
        <table className="trace-rows"><tbody>{e.rows!.map((r) => <tr key={r[0]}>{r.map((c, i) => <td key={i}><code>{c}</code></td>)}</tr>)}</tbody></table>
      ) : (
        <pre><code>{e.text}</code></pre>
      )}
      <p className="trace-from">
        <span>from {e.from}</span>
        {(href ?? e.href) && <Link href={href ?? e.href!}>{e.hrefLabel ?? "Open"}</Link>}
      </p>
    </div>
  );
}

export function TraceIsland({ data, storybookHref, figmaHref, componentCount }: {
  data: Record<TraceTarget, Record<Surface, Excerpt>>;
  storybookHref: Record<TraceTarget, string>;
  figmaHref: string;
  componentCount: number;
}) {
  const [target, setTarget] = useState<TraceTarget>("Button");
  const [surface, setSurface] = useState<Surface>("docs");
  const [view, setView] = useState("map");
  // Server and no-JS: wide, so both the map and the trace render.
  const wide = useMatchMedia(WIDE, true);
  const hrefFor = (s: Surface) => (s === "storybook" ? storybookHref[target] : s === "figma" ? figmaHref : undefined);

  const select = (s: Surface) => {
    setSurface(s);
    if (!wide) setView("trace");
  };

  const map = <SurfaceMap current={surface} onSelect={select} componentCount={componentCount} />;
  const trace = (
    <div className="trace">
      <div className="trace-top">
        <SegmentedControl aria-label="Trace" size={24} value={target} onValueChange={(v) => setTarget(v as TraceTarget)}>
          {(Object.keys(TARGET_LABEL) as TraceTarget[]).map((t) => <Segment key={t} value={t}>{TARGET_LABEL[t]}</Segment>)}
        </SegmentedControl>
      </div>
      <Tabs value={surface} onValueChange={(v) => setSurface(v as Surface)}>
        <TabList aria-label={`${TARGET_LABEL[target]} across the surfaces`}>
          {SURFACES.map(([s, label]) => <Tab key={s} value={s}>{label}</Tab>)}
        </TabList>
        {SURFACES.map(([s]) => (
          <TabPanel key={s} value={s}>
            <ExcerptView e={data[target][s]} href={hrefFor(s)} />
          </TabPanel>
        ))}
      </Tabs>
    </div>
  );

  if (wide) return <div className="surfaces-grid">{map}{trace}</div>;
  return (
    <Tabs value={view} onValueChange={setView}>
      <SegmentedControl aria-label="Surfaces view" fill>
        <Segment value="map">Map</Segment>
        <Segment value="trace">Trace</Segment>
      </SegmentedControl>
      <TabPanel value="map">{map}</TabPanel>
      <TabPanel value="trace">{trace}</TabPanel>
    </Tabs>
  );
}
```

The *Token* label stands for `--psi-fg-accent`, because four segments of a `SegmentedControl` must fit at 320px; the trace's tab list names the token in full.

function useOwnWidth<T extends HTMLElement>() {
  const ref = useRef<T>(null);
  const [width, setWidth] = useState(Infinity);
  useLayoutEffect(() => {
    const el = ref.current;
    if (!el) return;
    const ro = new ResizeObserver(([e]) => setWidth(e.contentRect.width));
    ro.observe(el);
    return () => ro.disconnect();
  }, []);
  return [ref, width] as const;
